## 🚀 How to Regenerate the App Using AI

1. Open an empty folder in your code editor.
2. Open [01_AI_PROMPTS_PLAYBOOK.md](./01_AI_PROMPTS_PLAYBOOK.md).
3. Copy and run each prompt sequentially (Stage 1 through Stage 8) using your preferred AI coding assistant.
4. Reference the corresponding component specifications ([02](./02_HTML_AND_DOM_SPEC.md) through [08](./08_ORCHESTRATION_AND_LIFECYCLE.md)) for in-depth verification of any feature.
5. Launch any local HTTP server (e.g. `python -m http.server 8000`) and navigate to `http://localhost:8000/`.
